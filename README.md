# Matos — Gestão de Aluguéis

Sistema web para administrar imóveis, proprietários, inquilinos, contratos, cobranças, IPTU, financeiro, comprovantes, relatórios, manutenção e acessos.

**Sistema em produção:** https://gestao-alugueis-jp.vercel.app

**Repositório oficial:** https://github.com/JoaoMonteirobr/matos-gestao-de-alugueis

## Desenvolvimento e publicação

- Código-fonte e histórico: GitHub, branch `main`.
- Hospedagem e publicação: Vercel, projeto `gestao-alugueis-jp`.
- Banco de dados e armazenamento privado: Supabase.
- Validação: workflow `Quality` (testes, análise estática e E2E).
- Após alterações na `main`, conferir o deployment de produção na Vercel e o funcionamento do domínio principal.

A renomeação do repositório não altera o domínio público, os dados, os pagamentos ou as permissões de acesso.
